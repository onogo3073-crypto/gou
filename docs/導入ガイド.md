# 球団運営AIエージェント 導入ガイド
作成日：2026年9月27日　対象：狭山西武ボーイズ・福島ピーチフェニックス 代表・事務局

## 1. 結論
**Claude Code に「球団運営スキル」を1つ入れるだけで、募集文・保護者連絡・スポンサー提案・試合報告・会計報告を、チーム情報に沿った文書として数分で作れる状態にしました。** コードを書く必要はありません。最初にやることは、チーム情報シートの「要記入」欄を埋めることだけです。
- 事実はチーム情報シートからだけ引用するため、実績や金額を AI が作り話で書き込むことを防ぎます。
- 子どもの氏名・写真、熱中症の中止基準、協賛金の税務（インボイス）を毎回チェックする仕組みを組み込みました。
- 仕上がりは MSゴシック10pt・行間狭め・金額右寄せ・年度中央の Word で出力されます。

## 2. なぜ作るのか・誰が使うのか
| 項目 | 内容 |
|---|---|
| 目的 | 代表・事務局の文書作業を減らし、保護者・スポンサーへの連絡の質とスピードをそろえる |
| 主な利用者 | 代表、事務局担当の保護者、コーチ |
| 読み手 | 入団希望の保護者、在籍選手の保護者、協賛企業、連盟関係者 |
| 使う場面 | 体験会前、試合当日・翌日、雨天・猛暑時、協賛依頼の時期、年度末 |

## 4. 5つの業務モードと依頼例
| モード | 依頼の例（このまま話しかけるだけ） | 出てくるもの |
|---|---|---|
| A 選手募集 | 「10月の体験会の告知文を作って。11月3日と11月10日、9時から」 | 告知本文・SNS短文・チラシ文面 |
| B スポンサー | 「地元の工務店向けに協賛提案書を Word で」 | 5構成の提案書＋想定問答5つ |
| C 保護者連絡 | 「明日の練習、暑さ指数で中止。LINE用に」 | 1行目で結論が分かる連絡文 |
| D 試合レポート | 「今日の試合結果：○○戦 5対3で勝利。SNSと保護者向けに」 | SNS速報・保護者向け・スポンサー向け |
| E 会計・計画 | 「2026年度上期の会計報告を表にして Word で」 | 収入・支出・残高の表 |

## 6. 導入の3ステップ（初心者向け）
1. **今日**：references/team_profile.md の「要記入」欄（練習場所・会費・連絡先・写真同意の状況）を埋めます。所要30分程度です。
2. **今週**：実際の連絡を1件だけエージェントに作らせ、いつもの文面と比べて足りない点を SKILL.md に書き足します。
3. **今月**：体験会告知とスポンサー提案の2つで本番運用し、使った文面を事例として残します。

## 7. 急ぎで確認していただきたいこと（2026年9月27日時点）
- **インボイス経過措置の縮小**：チームが適格請求書発行事業者でない場合、協賛企業が控除できる消費税は 2026年10月1日から 80％ → 50％に下がります（出典：国税庁「適格請求書等保存方式の概要」）。今期の協賛更新では、事前に企業へ説明しておくことをおすすめします。
- **福島ピーチフェニックスの基本情報**：公開情報の検索で確認できませんでした。チーム情報シートへの記入が必要です。
- **監督名の表記**：公開情報で「福井敬冶」「福井敬治」の2通りが見つかりました。正しい表記をご確認ください。

## 8. リスクと対策
| リスク | 対策 |
|---|---|
| AI が事実と違う実績・金額を書く | チーム情報シート以外の事実は「要確認」と表示させるルールにしています |
| 子どもの個人情報が外に出る | 同意確認がない選手は、外部向け文書で氏名・顔を出さないルールにしています |
| 連盟規程の読み違い | 規程の中身は推測させず、「最新の大会要項で要確認」と書かせています |
| 最終責任の所在 | 外部に出す文書は、必ず代表または事務局が目を通してから送ります |

## 9. 想定される反論と再反論
- **反論**：「テンプレートを作っておけば、AI は要らないのでは」
- **再反論**：定型の連絡はテンプレートで足ります。ただ、相手（保護者・企業・新入団希望者）や状況（勝ち負け・中止理由・税制変更）に合わせて書き分ける手間は残ります。このエージェントは、その書き分けとチェック（個人情報・熱中症基準・税務）を毎回同じ水準で行います。
- **残るリスク**：送信の最終判断は人が行う必要があります。自動送信はしない設計にしています。
