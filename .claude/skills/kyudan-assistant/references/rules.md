# 運営上のルール（根拠付き）

## 1. 子どもの個人情報・肖像
- 氏名・顔写真・学校名は個人情報保護法上の「個人情報」に当たります。任意団体でも個人情報を事業に使えば「個人情報取扱事業者」に該当し得ます（出典：個人情報保護委員会「個人情報保護法ガイドライン（通則編）」）。
- 運用ルール：入団時に「写真・氏名の掲載範囲（SNS／チラシ／スポンサー報告）」の同意書を取り、`team_profile.md` に同意状況を記録します。同意が確認できない選手は、外部向け文書で氏名・顔を出しません。

## 2. 熱中症による中止判断
- 日本スポーツ協会「熱中症予防運動指針」（出典：公益財団法人日本スポーツ協会『スポーツ活動中の熱中症予防ガイドブック』）
  - 暑さ指数（WBGT）31以上：運動は原則中止
  - WBGT 28〜31：厳重警戒（激しい運動は中止）
  - WBGT 25〜28：警戒（積極的に休憩）
- 当日の暑さ指数は環境省「熱中症予防情報サイト」で確認します。保護者連絡では「何時時点の、どの地点の値か」を書きます。

## 3. スポンサー税務（協賛企業への注意書き）
- 協賛金は、広告宣伝の対価（ロゴ掲出・看板など）といえる実態があれば企業側は広告宣伝費、対価性がなければ寄附金として損金算入に限度があります（出典：法人税法第37条、国税庁タックスアンサー No.5281）。
- インボイス制度：チームが適格請求書発行事業者でない場合、協賛企業の仕入税額控除は経過措置の範囲に限られます（出典：国税庁「適格請求書等保存方式の概要」）。
  - 2026年9月30日まで：仕入税額相当額の80％を控除可能
  - 2026年10月1日〜2029年9月30日：50％に縮小
- 2026年10月から控除割合が下がるため、協賛企業から問い合わせが増える可能性があります。提案書には「チームのインボイス登録の有無」を必ず明記します（登録番号は `team_profile.md` を参照）。
- 個別の税務判断は税理士への確認を勧める一文を添えます。

## 4. 連盟規程
- 大会参加資格・選手登録・移籍・投球数制限などは、日本少年野球連盟（ボーイズリーグ）の最新の規程・大会要項を根拠にします。エージェントは規程の中身を推測せず、「最新の大会要項で要確認」と書きます。
