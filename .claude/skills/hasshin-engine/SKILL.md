# 発信エンジン（定例化）

## 最初に読むもの
1. `references/ono_voice.md`：小野剛の言葉の材料庫。**ここにない主張を本人の考えとして書かない。**
2. `references/calendar.md`：週の定例枠と、会長の言葉シリーズの順番。
3. `.claude/skills/sns-poster/SKILL.md`：投稿の型・必須ハッシュタグ・承認ルール。

## 毎週の流れ（日曜夜に自動実行）
| 手順 | やること |
|---|---|
| 1 | Metricool で先週の投稿のリーチ・表示回数を取得し、`sns/log.md` に1行ずつ追記 |
| 2 | calendar.md の次の「会長の言葉」を選び、`python3 tools/make_card.py` でカード画像を作成（ファイル名は `sns/cards/YYYY-MM-DD_wNN.png`） |
| 3 | カードをコミット・プッシュし、公開URL（raw.githubusercontent.com）を Metricool の media に渡して **draft: true** で月曜20時に登録 |
| 4 | Google Drive「SNS投稿用（狭山西武ボーイズ）」に今週の写真があれば、水曜・金曜枠の下書きも作成。なければ代表に写真を依頼する文面を用意 |
| 5 | 代表への週次メモ（今週の下書き一覧・先週の数字・お願い1点）を `sns/weekly/YYYY-MM-DD.md` に保存 |

下書きの公開は、代表が Metricool アプリで内容を確認して承認してから行います（CLAUDE.md 第7条）。

## 書き方
- 会長の言葉は、材料庫の原文を崩さず引用し、前後に1〜3文の解説を添えます。
- 1行目は【会長の言葉 #NN】＋見出し。本文200〜400字。ハッシュタグは `#狭山西武ボーイズ #東大和狭山ボーイズ` を必ず入れ、合計8個前後。
- 締めの一文は毎回「見学は平日19時〜22時、狭山市南入曽で随時受付中です。」

## 個人アカウントとの線引き
- プロ野球界への提言・金融改革・お金の教育は、小野剛の個人アカウントで発信します。チーム公式では扱いません。
- 個人アカウントの投稿も、材料庫のC欄を代表から聞き取ってA欄に移してから作ります。
- 事業の資料（業務報告書・融資資料・取引先名）は、どのアカウントでも使いません。
