# 収益化エンジン

## 最初に必ず読むもの
1. `docs/収益化戦略.md`（全体方針・プラン案・90日計画）
2. `business/sponsor_pipeline.md`（営業管理表）と `business/kpi.md`（目標と実績）
3. `.claude/skills/kyudan-assistant/references/team_profile.md`（実績の唯一の根拠）

## 依頼ごとの動き方

| 依頼 | やること | 更新するファイル |
|---|---|---|
| 「スポンサー候補を3社追加して」 | 業種・接点・提案プランを決めて行を追加。会社の事実は依頼者の情報か公式サイトのみ。不明は【要確認】 | sponsor_pipeline.md |
| 「○○社向けに提案書を」 | `business/build_proposal.py` の表紙宛名・推奨プランを差し替えて実行（SNS数値は Metricool で最新化し `business/sns_実績_*.md` に残す） | output/、pipeline の状態を「提案済」へ |
| 「今週のスポンサー状況」 | 状態別件数・次回連絡日が過ぎた会社・今週の3アクションを出す | kpi.md の実績欄 |
| 「契約が決まった」 | お礼状（モードB）・SNSお礼投稿の下書き（sns-poster、承認前は draft）・請求書の項目案 | pipeline を「契約」へ、kpi.md |
| 「掲載報告を作って」 | 協賛期間中の試合結果・SNS実績を集めて報告書（モードD）をWord化 | output/ |
| 「外販の準備」 | 戦略書5章に沿って、導入資料・料金表・同意ルールを作成 | business/ |

## 状態の定義（sponsor_pipeline.md）
候補 → 接触済 → 提案済 → 検討中 → 契約 ／ 見送り。見送りは理由を1行残し、半年後に再提案日を入れます。

## 守ること
- 協賛金はチームの会計、外販の売上は代表個人の収入です。文書で混同しません。
- 外部向け文書に中学生の氏名・顔・学校名を載せません（同意確認済みでも提案書では「U15日本代表に2名」と人数で表します）。
- 金額は戦略書の「案」です。代表が確定するまで提案書には「（案）」と付けます。
- 協賛金の振込先は `business/private/振込先.md`（git管理外）にあります。このリポジトリは公開設定のため、口座情報をコミットしたファイルに書きません。提案書の【振込先】は output/ に出力するときだけ差し込みます。
- 部員1人の年間会費は336,000円です（月28,000円×12）。退団の相談は金額の大きい事案として、理由を kpi.md に記録します。
- 送信・投稿は必ず代表の承認後です。メールは下書きまでにします。
- 税務の説明は `rules.md` の「スポンサー税務」の範囲にとどめ、個別判断は税理士確認を勧めます。
